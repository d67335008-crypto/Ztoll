# Статус этапа 1

| Проверка | Статус |
|---|---|
| Исходный код написан | да |
| XAML / YAML / манифест — валидный XML/YAML, скобки сбалансированы | проверено |
| Компиляция `dotnet build` | **не проверена** — в среде разработки нет .NET SDK; проверяется первой сборкой в GitHub Actions |
| Юнит-тесты (xunit, 6 шт.: настройки, JSON, горячие клавиши) | написаны, запускаются в Actions |
| Запуск на Windows 10/11 | **не проверен** — нужен ручной тест после сборки |
| Ztoll.exe / Ztoll Setup.exe | создаются в Actions, в архиве проекта их нет |

Ручной чек-лист после первой успешной сборки:
- [ ] Остров появляется по центру сверху, показывает время и батарею
- [ ] Наведение/клик раскрывает, уход курсора сворачивает
- [ ] `Ctrl+Alt+Z` раскрывает и сворачивает
- [ ] Кнопки: Settings, тема, скриншот, блокировка, свернуть, выход
- [ ] Трей-меню и двойной клик по иконке
- [ ] Настройки сохраняются после перезапуска
- [ ] Автозапуск включается/выключается (Диспетчер задач → Автозагрузка)
- [ ] Установщик ставит, создаёт ярлык, удаляется через «Приложения»
